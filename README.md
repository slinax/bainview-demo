# Bainview — demonstration

Configurateur 3D de salle de bain qui tourne entierement dans le navigateur :
dimensions, parti d amenagement, materiaux, metre automatique, estimation,
fiche projet imprimable et export du modele 3D.

Aucun serveur, aucune donnee transmise : la configuration reste dans le
navigateur du visiteur.

Demonstration : https://slinax.github.io/bainview-demo/

Le moteur (`js/engine.mjs`) construit la piece a partir d un objet de
configuration ; aucune dimension n est codee en dur.
